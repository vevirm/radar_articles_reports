# Scan these now

To priority-scan works you found yourself:

1. Put the APA7 references in a Word document, one reference per paragraph.
2. Name the file exactly `scan_these_now.docx`.
3. Upload/replace it in this `priority_scan/` folder on `main`.
4. The **Priority — Scan APA7 DOCX Now** workflow starts automatically.

The DOCX is only a discovery list. The workflow resolves the underlying papers/news online,
checks the existing Radar for duplicates, and applies the normal A/B/C admission rules.
Nothing is force-added because it appears in the DOCX.

APA7 information is enough. DOI or URL is helpful when present but not required.
