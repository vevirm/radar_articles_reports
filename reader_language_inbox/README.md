# Reader Language inbox

Upload a returned `reader_language_results.json` here and commit it to `main`.
GitHub Actions validates the file and, if it is safe and still matches the current page text,
adds the approved wording to `reader_language/approved.json`.

This inbox never changes Radar evidence, Excel data, scores, dates, links, Deep Scan decisions,
or analytical reasoning. It only supplies optional display wording for approved reader-facing pages.
