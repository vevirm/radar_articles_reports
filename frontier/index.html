The technical classifier asks whether an admitted source shows a real change in Europe’s control, capability or exposure. It then checks three questions:

1 · Keep accessHow much control does Europe have over access and continuity?
2 · Stay strongDoes that position help or hurt European research, innovation or competitiveness?
3 · What can break?What could make either condition fail?

Placement uses two axes: A more control + stronger capability, B more control + a capability cost, C stronger capability + continued outside reliance, and D less control + weaker capability. A cell is used only when the source supports the row mechanism and both directions; generic words such as “foreign”, “risk”, “capacity” or “investment” are not enough.

Source quality is handled upstream when evidence is admitted to the Radar. It is not shown as a Matrix badge or used as a Matrix axis. After placement, the technical layer scores reach, reversibility, attention gap and actionability; those scores help order already-qualified findings and do not create Matrix evidence.

Attention gap is a proxy. A static repository cannot know with certainty what is already receiving mainstream EU policy attention. The score uses recency, source type and direct EU-policy linkage as a transparent proxy.
