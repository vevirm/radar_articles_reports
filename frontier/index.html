How the gate works

A Sovereignty-Frontier Signal qualifies when an observed event, decision, trend break or emerging development materially changes the answer to at least one of these questions:

1 · SustainCould the EU sustain the activity without reliance on a non-EU actor?
2 · CompeteIf it did so, would it remain competitive against the best available alternative?
3 · FailWhat could cause either of those conditions to fail?

Signals are then placed into A Opening, B Costly autonomy, C Productive dependence or D Double loss, and triaged for system reach, reversibility, policy-attention gap and actionability.

Implementation note — what is automatic

This static page reads the cumulative radar.json and applies a deterministic, transparent rule set. Strand C is the primary signal pool. Accepted A/B evidence can also surface when it contains an explicit observed change or decision. No external AI API is required, and the classifier never writes back to the corpus.

Attention gap is a proxy. A static repository cannot know with certainty what is or is not already receiving mainstream EU policy attention. The score therefore uses recency, source type and direct EU-policy linkage as a transparent proxy rather than presenting this criterion as known fact.
