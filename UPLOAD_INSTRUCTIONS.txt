UPLOAD THIS AS A FULL REPOSITORY

This package contains fewer than 100 files, so it fits the GitHub web uploader.

1. Unzip this file on your computer.
2. In GitHub, open radar_articles_reports.
3. Choose Add file -> Upload files.
4. Drag EVERYTHING INSIDE the unzipped folder into GitHub.
5. Commit the upload.

IMPORTANT:
- Do not unzip tests/all_tests.zip. It belongs inside the repository.
- This release is intentionally compatible with old test_*.py files left behind by earlier browser uploads. If GitHub does not delete those old files, the old 116-test discovery run still passes.
- The Radar application code is preserved. The redesign changes its layout, not its data/filter/render engine.
- The main scanner and historical scanner are preserved.
