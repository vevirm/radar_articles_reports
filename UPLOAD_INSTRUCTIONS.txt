UPLOAD THE WHOLE REPOSITORY

1. Download the ZIP supplied by ChatGPT.
2. Unzip it once on your computer.
3. Open your existing GitHub repository.
4. Choose Add file -> Upload files.
5. Drag EVERYTHING INSIDE the unzipped folder onto the GitHub upload page.
6. Make sure .github/workflows/radar-scan.yml and .github/workflows/historical-scan.yml appear in the upload list.
7. Click Commit changes.

Do not delete files manually. Do not edit individual files.

After upload, let the automatically triggered scan finish. This bundle carries a one-run recovery marker so that the scanner merges the larger pre-upload live radar corpus from Git history before applying the new quality cleanup; the upload therefore does not intentionally reset accumulated evidence or rotation cursors.
