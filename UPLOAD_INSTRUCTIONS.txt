UPLOAD THIS WHOLE REPO THROUGH THE GITHUB WEB UPLOADER

This version is designed for your exact constraint: browser uploads do not delete old files.

1. Unzip this download on your computer.
2. Open your GitHub repository.
3. Add file -> Upload files.
4. Drag everything INSIDE this folder into GitHub.
5. Commit the changes.

IMPORTANT: You do NOT need to delete old test files manually.
The main workflow now deliberately runs only tests/test_all.py, which loads the current bundled regression suite from tests/all_tests.zip. Any stale old test_*.py files left behind by previous browser uploads are ignored.

Do not unzip tests/all_tests.zip. It belongs in the repository exactly as-is.
