IMPORTANT: STALE .github WORKFLOWS NO LONGER BLOCK THE SCANNER
-------------------------------------------------------------
GitHub browser uploads have repeatedly left `.github/workflows/*.yml` at an older revision.
v17.20.44 is deliberately compatible with that situation. The scanner regression suite no
longer exits non-zero merely because hidden workflow YAML is stale. Visible Python runtime
guards handle the legacy hourly/six-hour Main workflow and prevent Main/Historical overlap.

The package still contains the preferred corrected workflows. If GitHub accepts them, Main
runs on the fixed four-hour schedule and Main/Historical share one concurrency group. If
GitHub leaves the old YAML in place, the upload-triggered Main scan still proceeds.
