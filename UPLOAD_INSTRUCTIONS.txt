UPLOAD THE WHOLE REPOSITORY — NO DELETING OR EDITING REQUIRED

1. Download and unzip this ZIP once on your computer.
2. Open your existing GitHub repository.
3. Choose Add file -> Upload files.
4. Drag EVERYTHING from inside the unzipped folder onto the GitHub upload page.
   Include the hidden .github folder.
5. Leave the commit message as "Add files via upload" if you want.
6. Commit directly to main.

You do NOT need to delete or edit individual files.
Files with the same names are replaced; new files are added.
