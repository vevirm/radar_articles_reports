EU R&I RADAR — FRESH REPOSITORY START
=====================================

This package is intended for a BRAND-NEW GitHub repository. It starts with the curated
200-item active evidence baseline (190 Strand A + 10 Strand B) but carries no previous
scanner run history, scan cursors, accepted-item archive, or old weak signals.

The first successful scanner run establishes the new repository's history. From then on,
normal incremental scanning, active-core curation, New/Updated page behavior, and archive
retention all continue normally.

SETUP
-----
1. Create a new GitHub repository and upload the complete contents of this package to main.
2. In GitHub, add your OpenAlex key as a repository Actions secret named exactly:

       OPENALEX_API_KEY

   Path: Settings -> Secrets and variables -> Actions -> New repository secret

   Never put the key in radar.json, a Python/JavaScript file, or any committed file.
3. Enable GitHub Actions for the repository if they are not already enabled.
4. Configure GitHub Pages for the repository (the site is served from the repository's
   Pages build).
5. The initial push is an immediate Main Radar scan trigger. The normal Main Radar schedule
   is then fixed at 00:17, 04:17, 08:17, 12:17, 16:17 and 20:17 UTC.

FRESH-START BEHAVIOR
--------------------
- radar.json ships with exactly 200 active A/B records.
- ab_archive starts empty.
- Strand C starts empty.
- scan_history and scan_state do not exist in the seed.
- The one-use fresh_repository_seed marker prevents old Git radar history or migration
  logic from being pulled into the first run.
- The first run uses the normal recent discovery overlap rather than a historical bootstrap.
- The marker is not written into normal scanner output, so it disappears automatically
  after the first successful scan.
- Security remains strict: repository credentials are not persisted during scanning, only
  radar.json may be committed by the Main scanner, abnormal output is rejected, and prior
  accepted A/B evidence is protected across the active 200 + ab_archive.

PAGE CHANGE
-----------
The External Shocks page is unchanged except that the one-shot “Construct one shock” toy
has been removed. No scanner logic depends on that toy.
