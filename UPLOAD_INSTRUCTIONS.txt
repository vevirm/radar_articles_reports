UPLOAD THE WHOLE REPOSITORY — NO DELETING OR EDITING REQUIRED

1. Unzip this ZIP once on your computer.
2. Open your existing GitHub repository.
3. Choose Add file -> Upload files.
4. Drag EVERYTHING from inside the unzipped folder onto the GitHub upload page.
   Include hidden folders such as .github if your file manager shows them.
5. Commit changes to main.

Files with the same names are replaced; new files are added. You do not need to delete old files manually.
