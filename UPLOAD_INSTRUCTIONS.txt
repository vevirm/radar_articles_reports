UPLOAD THE ENTIRE PACKAGE

1. Extract the ZIP on your computer.
2. Open the extracted folder.
3. In GitHub, open: vevirm/radar_articles_reports
4. Click: Add file -> Upload files.
5. Drag EVERYTHING INSIDE the extracted folder into GitHub.

VERY IMPORTANT:
The upload MUST include this folder:
  .github/workflows/
and inside it:
  radar-scan.yml

If .github is missing after upload, the scanner cannot run.

6. Replace existing files when needed.
7. Commit directly to main.

WHAT HAPPENS NEXT
- That commit immediately triggers the first workflow run: "R&I Radar Scan".
- The scanner collects and filters the radar candidates and writes the results to radar.json.
- The same workflow then requests a GitHub Pages rebuild, so the fresh results appear on the site.
- After that, GitHub runs the scan automatically every 12 hours.
- You can also run a scan at any time from Actions -> R&I Radar Scan -> Run workflow.
