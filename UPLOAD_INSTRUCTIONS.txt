UPLOAD THIS PACKAGE

1. Extract the ZIP on your computer.
2. Open the extracted folder.
3. In GitHub, open vevirm/radar_articles_reports.
4. Click Add file -> Upload files.
5. Drag EVERYTHING INSIDE the extracted folder into the GitHub upload area, including the .github folder.
6. Commit directly to main.
7. Wait a few minutes.
8. Open: https://vevirm.github.io/radar_articles_reports/

The upload itself should trigger the first scan. If it does not, go to:
Actions -> R&I Radar Scan -> Run workflow.

Do not change GitHub Pages away from:
Deploy from a branch -> main -> /(root)
