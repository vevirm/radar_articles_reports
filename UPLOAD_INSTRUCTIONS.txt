V17.12.1 PRESENTATION-FIRST UPLOAD

1. Upload/replace the repository files on main.
2. Do NOT run R&I Radar Scan yet. This package does not trigger it on push or on a schedule.
3. Wait only for GitHub Pages to refresh, then inspect:
   - /                      main radar
   - /frontier/             Insight Summary
   - /priorities/           Opportunities & Risks
   - /briefing/             Radar Insights
4. A push may run the short "Presentation smoke check" GitHub Action. It reads only the bundled repository files and never runs discovery.
5. When the presentation is accepted, start a live scan manually:
   Actions -> R&I Radar Scan -> Run workflow

The bundled radar.json is already populated. The first upload is therefore a presentation/deployment check, not a discovery run.
