UPLOAD / REPLACE THE REPOSITORY
================================

1. Extract this ZIP.
2. Open your GitHub repository: vevirm/radar_articles_reports
3. Add file -> Upload files.
4. Upload EVERYTHING inside the extracted folder to the repository root, replacing existing files.
5. Commit directly to main.

CRITICAL CHECK
--------------
After the commit, open the Actions tab.
You must see a workflow named:

    R&I Radar Scan

If you do NOT see it, the hidden .github folder did not upload.
In that case create this file in GitHub:

    .github/workflows/radar-scan.yml

and copy the contents from:

    WORKFLOW_BACKUP/radar-scan.yml

FIRST SCAN
----------
The commit to main triggers the first scan immediately.
Because radar.json and findings.json are reset to pending in this package, that first scan backfills A/B from 2026-04-01 to the present, builds the one-sentence evidence briefing from the accepted corpus, and gives Strand C a 7-day first-run lookback.
The workflow then runs again every 12 hours. Every run updates both radar.json and findings.json together. Later C scans use a 48-hour overlap.
If you are upgrading an existing live repository, the scanner detects the pending package template and recovers the previous committed radar.json from Git history before continuing, so the accumulated A/B corpus is retained and its findings are backfilled automatically.
It can also be run manually from Actions -> R&I Radar Scan -> Run workflow.

If you previously created an OPENAI_API_KEY secret for this repository, it is not used by this version.
