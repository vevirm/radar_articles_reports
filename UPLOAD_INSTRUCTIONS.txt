UPLOAD THE WHOLE REPOSITORY
===========================

This ZIP is a COMPLETE repository snapshot, not a patch.

1. Unzip the package.
2. Open the `radar_articles_reports-main` folder.
3. Upload/replace the COMPLETE contents of that folder on top of the existing GitHub repository.
4. Let files with the same names replace the older versions.

IMPORTANT ABOUT GITHUB'S HIDDEN WORKFLOW FOLDER
-----------------------------------------------
The package includes the intended `.github/workflows/` files. Some browser/Windows upload
flows do not actually replace that hidden folder. The visible scanner code is therefore
kept compatible with the older workflow too:

- the old hourly/6-hour Main gate is aligned by scanner state to the intended real four-hour slots;
- its old separate rescue dispatch is disabled by visible config;
- the Historical scanner ignores the stale 10-minute minimum-runtime environment setting;
- the runtime guard prevents Main/Historical source retrieval from colliding.

If the hidden workflow stays old, GitHub may show harmless short no-op Main workflow runs
between real scan slots. A real scan is the run where `Run radar scan` lasts minutes rather
than 0 seconds.

Do not cherry-pick individual files. Use the whole repository package.
