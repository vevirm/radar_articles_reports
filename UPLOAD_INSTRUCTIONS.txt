MANUAL CANDIDATE LIST
  python scripts/manual_ingest.py PATH_TO_LIST --state radar.json

Supported: DOCX, PDF, CSV, JSON, YAML/YML, TXT, Markdown.
Use --no-fetch for comparison/registration only; use --refresh to reprocess the same file hash.
Use --links-validated when supplied URLs were tested by the curator; this records reachability only and does not bypass source-evidence checks.

IMPORTANT
- Manual list entries are candidates, never automatic evidence or automatic matrix entries.
- Metadata-only records defer pending retrieval.
- Secondary references and forthcoming/unpublished records stay outside the matrix.
- Manual ingest preserves last_updated and all live-scan cursors/history.
