IMPORTANT ABOUT GITHUB'S HIDDEN WORKFLOW FOLDER
-----------------------------------------------
This release repairs `.github/workflows/radar-scan.yml` and
`.github/workflows/historical-scan.yml`. v17.20.42 accidentally shipped the new workflow-contract
tests together with the old workflow YAML, so GitHub correctly stopped before the scanner ran. Make sure the complete `.github` folder is included
in the upload. The repaired workflows use one shared scanner concurrency group, Main runs
on the fixed four-hour schedule, and Historical no longer runs on every repository push.
