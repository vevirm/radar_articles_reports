UPLOAD-ONLY INSTRUCTIONS — v17.18.1

1. Unzip this ZIP once.
2. Open your existing GitHub repository.
3. Choose Add file -> Upload files.
4. Drag EVERYTHING INSIDE the unzipped repository folder onto the GitHub upload page.
5. Before Commit changes, use the upload list to make sure these TWO files are present:
      .github/workflows/radar-scan.yml
      .github/workflows/historical-scan.yml
   They are important because GitHub only schedules workflows from the .github/workflows folder.
6. Leave the commit message as Add files via upload if you like.
7. Click Commit changes.

You do not need to delete or edit anything.

If the two .github/workflows files are not shown in the upload list, drag the .github folder from the unzipped repository onto the same GitHub upload page as well. This is still upload-only; no editing is required.
