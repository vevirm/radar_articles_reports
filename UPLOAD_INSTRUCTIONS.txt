CLEAN FRESH START
=================

This package is intended for an EMPTY GitHub repository.

1. Create a new empty repository (do not initialise it from the old Radar repository).
2. Upload the contents of this package, preserving folders including .github/workflows/.
3. In repository Settings -> Secrets and variables -> Actions, add:
      OPENALEX_API_KEY
   with your OpenAlex API key as its value.
4. The first push can trigger R&I Radar Scan automatically. You can also use Actions ->
   R&I Radar Scan -> Run workflow.
5. The repository begins with exactly 200 baseline A+B records (190 A + 10 B).
   There is no inherited scanner state, scan history, A/B archive or Strand C.
6. On the first successful scanner run, the scanner creates new state/cursors/history from
   that run onward and the workflow consumes/deletes FRESH_START.
7. Later scans continue incrementally from the state created by this repository itself.

There is no legacy regression-test directory in this package. Runtime safety is enforced by
fresh-start preflight and post-scan output validation instead of old version-specific tests.
