UPLOAD THIS WHOLE REPOSITORY TO GITHUB

1. Unzip this ZIP once.
2. Open your GitHub repository.
3. Choose Add file -> Upload files.
4. Drag EVERYTHING INSIDE the unzipped folder onto the GitHub upload page.
5. IMPORTANT: before committing, the upload list must include these two paths:
      .github/workflows/radar-scan.yml
      .github/workflows/historical-scan.yml
   They are ordinary repository files and are required for the four-hour scanners.
6. Click Commit changes.

Do not delete or edit anything manually.

After this upload:
- Main Radar scan: every 4 hours.
- Historical scan: every 4 hours, offset from Main.
- Runtime working-tree noise cannot throw away a finished scan; only the allowed JSON result file is staged.
- Reader evidence pages load the current radar.json directly and quality-rank admitted evidence.
