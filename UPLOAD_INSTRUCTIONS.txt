R&I RADAR — UPLOAD INSTRUCTIONS
===============================

BEFORE YOU UPLOAD
-----------------
Add one GitHub Actions repository secret:

Name: OPENAI_API_KEY
Value: your OpenAI API key

GitHub path:
Settings -> Secrets and variables -> Actions -> New repository secret

Do NOT put the API key into any repository file.

UPLOAD
------
1. Extract this ZIP.
2. Open GitHub repository: vevirm/radar_articles_reports
3. Add file -> Upload files.
4. Upload EVERYTHING inside the extracted folder, preserving folders, and replace existing files.
5. Commit directly to main.

FIRST SCAN
----------
That commit triggers "R&I Radar Scan" immediately.
Go to Actions and you should see it start.
The scanner performs separate web-research passes for A, B and C, writes radar.json,
and then requests a fresh GitHub Pages build.

12-HOUR SCANS
-------------
After the first run, the workflow runs at 00:17 and 12:17 UTC every day.
You can also run it manually from Actions -> R&I Radar Scan -> Run workflow.

IMPORTANT .github CHECK
-----------------------
Because the workflow lives in .github/workflows, verify after upload that Actions shows
"R&I Radar Scan" and that .github/workflows/radar-scan.yml was updated.
If a file uploader omits the .github folder, use the visible backup file:
WORKFLOW_BACKUP/radar-scan.yml
and paste it into .github/workflows/radar-scan.yml with GitHub's workflow editor.

GITHUB PAGES
------------
Keep Pages set to:
Deploy from a branch -> main -> /(root)
