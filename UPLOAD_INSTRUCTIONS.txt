R&I GEOPOLITICS RADAR — WHOLE-REPOSITORY UPLOAD

1. Upload the complete contents of this repository bundle to the repository root.
2. Add repository secret OPENALEX_API_KEY.
3. Main scanner standard budget is 24 minutes on every scheduled/manual scan.
4. Historical scanner standard budget is 15 minutes and accepts only publication dates strictly older than the rolling six-month cutoff.
5. radar.json and historical/historical.json are generated live-state files. This bundle deliberately ships radar_seed.json and historical/historical_seed.json instead, so uploading a new whole-repo version cannot overwrite a newer live corpus. Existing live files remain authoritative. A genuinely new repository bootstraps from the seed files automatically.
6. Main A/B is cumulative within its live evidence policy; 200 is the starting baseline, not a cap. Strand C is temporary: every C row must be anchored to substantive Strand A evidence and expires exactly 60 days after first_seen.
7. Browser pages have no repository write credential. Scanner checkout uses persist-credentials:false; only the permitted generated JSON file is authenticated and committed after validation.
