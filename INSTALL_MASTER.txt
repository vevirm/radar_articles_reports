MASTER — UPDATE ONLY THE ISOLATED MASTER FILES
====================================

This package is a NEW, isolated manual workflow. It never replaces the scanner,
workbooks, Pages, or any existing workflow.

1. EXTRACT this ZIP on your computer. Do not upload the ZIP unchanged.
2. In your existing GitHub repository, upload the extracted files/folders while
   preserving the complete paths (especially .github/workflows/master.yml).
   These paths belong only to the master workflow. If you installed a previous master package, replace only its master-specific files; do not replace any other workflow or repository content.
3. Commit them to your chosen branch.
4. Click Actions > master > Run workflow. Default maximum: 28 per section.
5. The run re-reads:
      stuff/source_merit_ranking.xlsx
      Relevance Stuff/relevance_stuff.xlsx
   and generates / updates ONE Word document:
      reasoning outcomes as planned/Master_Foresight_Reasoning.docx

Only the DOCX is committed by the workflow. No publishing, scheduling,
external AI calls or changes to the Excel files.

For the detailed premises, formal causal/topological rules and exceptions,
read master_reasoning/docs/RULEBOOK.md. For controls and setup,
read master_reasoning/README.md.

IMPORTANT PRIVACY LIMIT: If your existing GitHub repository is PUBLIC,
the committed DOCX is publicly accessible directly on GitHub even though
it is NOT sent to GitHub Pages. Keep the repository PRIVATE if you truly
need private-use reasoning outcomes.

SEPARATE RULES GUIDE (not included inside the outcomes report):
master_reasoning/docs/GENERAL_RULES_PLAIN_LANGUAGE.docx
master_reasoning/docs/GENERAL_RULES_PLAIN_LANGUAGE.md
The output DOCX now uses a reading-first analytical style; the underlying inference gates remain unchanged.
