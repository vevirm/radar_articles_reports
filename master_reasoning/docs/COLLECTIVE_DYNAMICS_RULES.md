# Collective and nonlinear dynamics inside `master` — inference rules, not categories

This is an **owner-only methodological companion**. The five-section DOCX generated by the manual `master` workflow remains an outcomes report. It does **not** print these ten concepts as a checklist.

## What changed in v8

The engine still (1) admits verified, independent, geographically/temporally compatible records; (2) builds conditional directed, signed structures from reviewed bridges; and (3) considers authored conjunctive (AND-gated) interactions. A new module, `master_reasoning/collective.py`, asks what new *collective behavior or reconfiguration* might follow from **interactions among those structures**.

We deliberately distinguish:

- **Observed source claim:** what the admitted record actually reports (sometimes merely an announcement).
- **Conditional causal bridge:** an explicit model assumption that can fail, not an empirically estimated effect.
- **Derived collective mechanism:** a testable implication of several connected bridges under stated conditions.
- **Measured nonlinear dynamics:** tipping points, synchronization, contagion coefficients and hysteresis require longitudinal/actor-level observations not currently supplied by these workbooks. The engine does not assert them as measured facts.

### Absolute admission rule

For the new layer, every supporting anchor must be workbook-verified, have positive evidential directness, a different and known publisher family, the same defined scope, and dates within a three-year compatibility window. Every modelled edge must have *both* endpoints anchored. The engine rejects combinations failing any gate. No number of unverified leads can compensate.

## The ten ideas in the mix

| Concept | What it contributes to the reasoning | What the current data cannot prove |
|---|---|---|
| Collective dynamics | Joint effects from separately documented initiatives competing for the same interface | A measured population-wide behavioral response |
| Emergent behavior | New roles, dependencies and allocation institutions not specified in individual actions | An observed spontaneous institution without actor evidence |
| Self-organization | Alternative cooperation and access routes formed by actors adapting to constraints | That reorganization happened without central planning |
| Social contagion | Propagation along a multistage, connected dependence structure; test for actual behavioral diffusion | Contagion rates, social exposure networks or infection-like transmission |
| Synchronization | Whether several independently documented actions could generate demand at the same conversion gate | Actual simultaneous execution inferred from publication dates |
| Cascade dynamics | Chain-specific delayed and downstream consequences, conditional on each transmission step | That an observed shock has propagated causally |
| Phase transitions | Hypotheses that activation of a final necessary complement or a binding restriction changes the operating regime | A numerical critical threshold or empirically detected tipping point |
| Swarm dynamics | Local adaptations that might generate an aggregate organization without a central design; only an analogy without micro-interaction observations | Collective motion or swarm behavior measured at actor level |
| Complex adaptive systems | Actors may adjust routes, contracts and behavior in response to constraints, changing the future network itself | A calibrated agent-based model of adaptation |
| Nonlinear social dynamics | Joint conditions, gate effects and path dependence where inputs need not produce proportional outputs | Estimated nonlinear elasticities, feedback gains or hysteresis |

**No automatic ten-label generator:** a concept enters a reported inference only if the relevant mechanism has structural premises. Some are presently methodological lenses or tests for future evidence, rather than active result-generating motifs.

## Formal rule family

`frontier` describes a graph `G=(V,E)` with observed, verified nodes `V` and reviewer-specified signed conditional bridges `E`. The conjunction registry adds a hyperedge `H: {A,B,C,...} -> Z`, where `{A,B,C,...}` are all independently anchored. The new rule layer attempts *composition*, e.g. `conjunction + delayed cascade`, not just one more generic template.

### C1 — Adaptive rerouting after an inhibitory constraint

**Admit if:** at least two distinct modeled upstream routes converge on an interface, an explicit restrictive path also touches it, and there is a grounded downstream route or cut-effect. **Infer:** actors can collectively reroute towards still-open alternatives, changing dependency and bargaining power. A control can therefore reorganize a system, not simply slow it. **Reject as observed** without evidence of the actual route choices. Test denials, new partnerships and time-varying access shares.

### C2 — Joint activation and possible regime change

**Admit if:** an authored AND-gated rule matches all required verified anchored objects *and* there are multiple relevant modeled routes. **Infer:** making the last scarce complement usable can have a different marginal effect from adding more of a complement that is already abundant. The seat of influence can shift to whoever controls the final interface. **Do not infer** a numerical threshold, actual discontinuity or tipping date. Test realized conversion as the last complement comes online versus other conditions.

### C3 — Specific cascade path

**Admit if:** an actual, directed, positive path of at least three bridges passes through the focal node, with independently anchored endpoints. The path is named from its start through intermediate systems to its destination. **Infer:** change at the start can appear later and elsewhere if all links transmit as assumed. **Reject** generic "everything affects everything" reasoning; the path must be inspectable and each bridge falsifiable. Actor imitation is not assumed merely because a dependency path exists.

### C4 — Distributed coordination and emergent allocation

**Admit if:** independently anchored routes converge on a shared interface, branch to distinct downstream systems, and cross several domains. **Infer:** uncoordinated improvements can create collective governance or allocation needs at an interface no initiative set out to control. **Do not infer** a factual absence of central direction from missing central-coordination evidence.

### C5 — Collective lock-in and possible persistence

**Admit if:** a common positive-path cut is identified and separately anchored alternative upstream routes still converge there. **Infer:** the diversification of individual paths can create aggregate dependence on the common gate; choices around that gate could persist when the original pressure abates. **Reject as observed hysteresis** until reversibility/switching cost data are collected.

### C6 — Temporal compression and conditional synchronization

**Admit if:** at least three independent, non-projected **operating** expansion actions with different subjects and compatible scopes are documented within 180 days. **Infer:** *if their execution also coincides*, several separate adoption waves may arrive together at a shared interface. **Do not call** publication coincidence observed synchronization. Test actual implementation dates, demand curves, queueing and common timing.

### C7 — Feedback only from an actual directed cycle

**Admit if:** the current verified-endpoint model graph contains a directed cycle. **Infer:** a potential return channel whose sign and gain still require measurement. A cycle in the hypothetical graph is **not** a verified feedback loop. If there is no directed cycle, the model must not draw or report one. Earlier engine versions had no verified-anchored feedback cycles.

## Composing mechanisms rather than enumerating them

The engine selects a primary mechanism based on whether its *specific* structural prerequisites are satisfied, then a secondary mechanism **from another family**, if available. Examples:

- `joint activation + cascade`: the last essential complement unlocks a path, shifting where the downstream effect occurs.
- `adaptive rerouting + cascade`: a restriction can reroute actors and create a remote exposure.
- `adaptive rerouting + regime change`: a temporary control could solidify into a new institutional arrangement.
- `distributed coordination + transition`: independent gains make a shared interface strategically decisive.

Each combined reading records its rule IDs, interpretable narrative, underlying verified-claim count, and explicit disconfirmation tests in memory while the report is written. The DOCX intentionally displays the *future consequence*, not the internal IDs or a technical scorecard.

## Eight scenarios

The existing three scenario axes and eight worlds remain unchanged. Conditional collective mechanisms are applied **within** each combination: portability can enable alternative self-organization; lock-in can reinforce fragmentation; funding conversion can permit propagation; failed conversion can create shared gates and accumulated demand; security limits can concentrate coordination into protected corridors. This adds *dynamics* to the world descriptions, not fabricated probabilities or new evidence.

## Model limits worth remembering

The system does **not** ingest social-network adjacency lists, agent trajectories, adoption-frequency time series or intervention outcomes. It cannot estimate a tipping point, a contagion reproduction number, a phase-transition exponent, network hysteresis or real synchronization. A source claim about a plan is still not a verified outcome, and an analyst-authored bridge stays defeasible. The new rules are structural abductive tests, not automatic empirical proofs.
