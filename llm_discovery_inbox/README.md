# Manual LLM Research Discovery Inbox

Upload `llm_research_results.json` here using **GitHub → Add file → Upload files**. For additional batches, give each file a unique name ending in `.json`.

The **Strand A — Import LLM Research Discoveries** GitHub Action runs after your manual commit, checks actual sources without any LLM API, and appends only evidence-qualified Strand A publications into the existing Main Radar pending Deep Scan. Never put research results into this README.

See `LLM_DISCOVERY_SETUP.md` in the repository root for the full workflow.
