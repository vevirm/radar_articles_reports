# V17.13.28 — source-specific Radar claims + source-summary Excel

- Main Radar no longer accepts reusable thematic slogans as publication claims.
- `whatForEuRiGeo` now prioritises concrete source propositions and rejects scanner/review scaffolding, method boilerplate and document debris.
- Main Radar claim budget is intentionally longer (up to roughly 300 characters) than Read/Matrix so it can state actor + mechanism + consequence.
- Existing generic stored claims were migrated to source-specific claims where the saved evidence supported one.
- Weak signals with only headline-level evidence use the concrete headline/event rather than the generic “this may affect European access…” filler.
- Excel adds a `What sources say` sheet and source-summary bullet columns in Ranked sources and Technical evidence. Bullets are source-grounded; metadata-only saved records are marked as such.
- Four further high-confidence legacy Strand-A contaminants were removed when the specificity audit showed that their saved evidence did not establish an EU R&I geopolitical mechanism.
- Matrix semantic logic, 4-month core / Highest-to-6-month rule, English-publication boundary and six-hour catch-up scheduler remain unchanged.
