# V17.13.0 changelog

## Reader experience

- Replaced `read/` with an eight-issue hierarchy. Each main issue opens into branches and subissues, with live evidence drawn from the current radar state.
- Simplified Matrix row/column/cell terminology around **control** and **competitiveness**.
- Added `frontier/quick/`, a stripped-down Matrix with no bibliography, author detail, classifier scores or method text.
- Changed the main radar so source/bibliographic detail is collapsed by default.
- Simplified the Risks & opportunities source line to source + date.
- Added explicit plain-language rewrites for the e-hryvnia, cyber-governance, AI4S, CEPS technology-mapping and EU–India/open-hardware examples. The Kotasthane biography is no longer used as a reader-facing finding.

## Discovery and admission

- Added a conservative implied-strategic-context route. Literal `geopolitics` is not required when at least two independent strategic mechanisms triangulate the relevance.
- Added strategic families for dependency/control, capability/competition, international coordination, security/resilience, rules/standards power and research-talent position.
- Added a rotating `finding-context` scholarly query lane derived from themes already visible in the current radar.
- Added implicit-strategic search formulations to the broad scholarly bank.
- Changed priority-person scanning to fallback attention when normal scholarly yield is thin or matrix coverage is very sparse.
- Disabled the protected weak-signal follow-up query wave and capped Strand C at 15% of the public A+B+C corpus after merge. This is a ceiling, not a minimum quota.

## Recency and matrix flow

- Enforced a hard rolling four-calendar-month floor across A, B, C and matrix-only evidence.
- Historical/stubborn matrix recovery can no longer widen the public date window.
- Removed the Matrix's hidden `dynamic` pre-filter so every admitted substantive finding reaches the classifier. Items can still fail classification when their evidence does not support a row and direction.
- Bundled the newer uploaded radar state, pruned it to 28 April 2026 onward, and re-normalised reader-facing claims. No fresh external discovery scan was claimed during packaging.
